# 复刻参考站动态背景：提示词与验收手册

目标参考站：<https://bistutzyy.github.io>（仓库只含生成产物：Hexo 7.3.0 + Butterfly 5.5.4）。
本文记录本站对齐它的完整方法论、实测参数和可复用提示词，便于以后升级主题或换站时复现。

## 0. 结论先行

参考站的"动态背景"**不是手写 canvas**，而是 Butterfly 主题内置的 5 个背景/交互特效，
脚本来自 `butterfly-extsrc@1.1.6`（由主题自动注入）。早期本站用自研 canvas 近似实现，
参数模型与脚本来源都不同，所以怎么调都不像；换成主题内置特效后，视觉效果与参考站同源。

经验：**不要向 AI 描述"做一个炫酷的动态背景"，要直接指定"开启主题的哪些配置块、参数是多少、如何验收"。**

## 1. 参考站实测规格（提取自渲染后的 HTML/CSS）

脚本来源（主题 `plugins.yml` + `cdn.js` 组装，参考站用 jsdelivr）：

- `https://cdn.jsdelivr.net/npm/butterfly-extsrc@1.1.6/dist/canvas-nest.min.js`
- `https://cdn.jsdelivr.net/npm/butterfly-extsrc@1.1.6/dist/canvas-ribbon.min.js`
- `https://cdn.jsdelivr.net/npm/butterfly-extsrc@1.1.6/dist/canvas-fluttering-ribbon.min.js`
- `https://cdn.jsdelivr.net/npm/butterfly-extsrc@1.1.6/dist/fireworks.min.js`
- `https://cdn.jsdelivr.net/npm/butterfly-extsrc@1.1.6/dist/activate-power-mode.min.js`

参考站渲染出的参数（Butterfly 5.5.4；本站 5.7.0 的配置键名以其 `_config.yml` 为准）：

| 特效 | 配置块（5.7.0 键名） | 参考站参数 | 本站取值 |
|---|---|---|---|
| 蛛网连线 | `canvas_nest` | `color: '0,0,255'` `opacity: 0.7` `zIndex: -1` `count: 99` `mobile: true` | 同左，`mobile: false` |
| 鼠标彩带 | `canvas_ribbon` | `size: 150` `alpha: 0.6` `zIndex: -1` `click_to_change: false` `mobile: true` | 同左，`mobile: false` |
| 飘带 | `canvas_fluttering_ribbon` | `enable: true` `mobile: true` | 同左，`mobile: false` |
| 点击烟花 | `fireworks` | `enable: true` `zIndex: 9999` `mobile: true` | 同左，`mobile: false` |
| 打字特效 | `activate_power_mode` | `colorful: true` `shake: true` `mobile: true` | 同左，`mobile: false` |

主题自带的配套 CSS（无需手写）：

- 所有 canvas 与背景层 4s 淡入：`to_show` / `ribbon_to_show` 动画；
- 烟花画布：`position: fixed; z-index: 9999; pointer-events: none`；
- 深色模式在 `#web_bg:before` 叠 `rgba(0,0,0,0.7)` 遮罩；
- 整屏 banner 视差：`background-attachment: fixed`。

两个易错点：

1. `canvas_ribbon` 在配置文件里的键名是 **`click_to_change`**；`data-click` 只是它渲染到 `<script>` 标签上的 DOM 属性名；
2. `mobile` 的判定是**UA 正则**（Android/iOS 等），不是视口宽度。桌面浏览器缩到 390px 宽仍会运行特效，只有移动端 UA 才停用。测试移动端行为必须模拟移动 UA。

## 2. 本站实现方式（已落地并验证）

- 依赖：`hexo-butterfly-extjs@1.5.8`（内含 `butterfly-extsrc@1.1.6`，与参考站同版本）；
- CDN 配置：`third_party_provider: local`，脚本构建期生成到 `dist/pluginsSrc/butterfly-extsrc/dist/`，运行不依赖外部 CDN；
- 自研 canvas 与左下角"动效开关"已移除；首页 Hero 文案注入（kicker/快捷链接/feed 标题）不是背景特效，保留于 `source/js/hero.js`；
- 移动端 `mobile: false` 为有意取舍：手机上不运行画布，桌面端与参考站一致。
- 点击特效为自研「准星脉冲」（`source/js/click-pulse.js`），替代主题 fireworks；`activate_power_mode` 改为 `colorful: false, shake: false` 的安静模式。

代价说明（客观记录）：`local` 会把 `plugins.yml` 里全部第三方脚本写入 `dist`，本站构建产物约 **53 MB**（其中 `pluginsSrc/` 52 个文件）。
若在意体积，可改用替代方案：保留 `third_party_provider: jsdelivr`，仅把 5 个特效脚本在 `tools/prepare.mjs` 中 vendor 到站内并用 `CDN.option` 覆盖路径。

## 6. 首页过渡增强（本站自有设计，参考站没有整屏 Hero）

保留 100svh Hero 的同时让首屏不做"静态面板"、滚过折痕不突兀。全部在 `source/css/custom.css`，无新增 JS：

- Hero 不再绘制实色背景（`background-color: transparent`、`background-image: none !important`），插画移到 `::before`：`opacity: .5`、`mask-image: linear-gradient(180deg, #000 42%, transparent 96%)`、`animation: hero-drift 56s ease-in-out infinite alternate`（只动 `translate`/`scale`，GPU 合成）。固定 canvas 层（z-index -1）因此从第一屏就可见。
- `::after` 是渐变纱：浅色 `rgba(249,251,255,.32) → .14(34%) → 0(62%)`；深色 `rgba(20,26,34,.78) → .42(40%) → .12(72%) → 0`。**底部 alpha 归零**是折痕无断层的关键——Hero 底部与 feed 背景完全同色。
- 滚动联动（渐进增强）：`@supports (animation-timeline: scroll())` 下叠加 `hero-scroll-fade`（0→100vh，opacity → .12），只动 opacity，与漂移的 translate/scale 不冲突；不支持的浏览器自动退回循环动画。
- `prefers-reduced-motion: reduce`：关闭漂移与滚动淡出。
- 移动端（canvas 关闭）：保留插画漂移；`#site_social_icons` 原为深色 banner 设计的白色图标，已改为 Hero 配色。

验收（`tools/browser-check.mjs`）：Hero `background-image: none`、底色透明、`::before` 含插画且 `opacity < .8`、动画名含 `hero-drift`；`SCREENSHOT_DIR` 下增加滚动中段截图，人工核对 0 / 50vh / 100vh 三档在浅色/深色/移动端均无断层。

附可复用提问模板：

```text
首页是静态的、滚到内容区时背景动效突然出现，想让过渡自然。请先找出遮挡动态背景的实色层
（通常是 hero 的 background-color 与 background-image，或内联 style），原则是"删除遮挡"而不是
"用渐变掩盖断层"：
1. 把插画移入 ::before，设置 opacity/mask 让固定的背景 canvas 从第一屏透出；
2. ::after 只做对比度纱层，且底部 alpha 归零，保证折痕两侧同色；
3. 可选：用 @supports (animation-timeline: scroll()) 做滚动淡出，并为 prefers-reduced-motion 关闭；
4. 验收：滚动 0 / 50vh / 100vh 截图对比折痕两侧颜色与动效连续性，测试断言 hero 计算样式。
```

## 7. 点击特效：准星脉冲（自研，替代 fireworks）

主题内置的 fireworks 是多色粒子爆炸，视觉偏"烟花"。本站改为一个更克制的 HUD 式点击反馈，实现于 `source/js/click-pulse.js` + `source/css/custom.css` 的 `.click-pulse`：

- 结构：`span.click-pulse`（`position: fixed`、0×0 锚点、`pointer-events: none`、`z-index: 1000`）内嵌 `::before`（环）、`::after`（方核）与 4 个 `<i>`（准星刻度，`--tick` 旋转 0/90/180/270°）。
- 动画：环 28px 从 0.35→2 倍扩散淡出 560ms；3px 直角方核 320ms；刻度沿轴 11px→28px 外滑 460ms；缓动统一 `cubic-bezier(.16,.84,.34,1)`。
- 颜色：`--click-accent` 浅色 `#167e9b`、深色 `#7fc4dd`（深色下另加极轻 `drop-shadow` 辉光）。
- 行为：`pointerdown` 触发（鼠标左键 / 触屏 / 笔）；spawn 时实时检查 `prefers-reduced-motion`；并发上限 10，700ms 自动移除；无 rAF、无 canvas。
- 配置：`fireworks.enable: false`；`activate_power_mode` 改为 `colorful: false, shake: false`。

验收（`tools/browser-check.mjs`）：点击后 `.click-pulse` 出现且 0.8s 内清理干净；`reducedMotion: reduce` 模拟下不再生成；首页产物不含 `fireworks.min.js` 且含 `/js/click-pulse.js`。

附可复用提问模板：

```text
把主题自带的点击烟花换成更克制的点击反馈，要求：1px 细线、单色、无粒子、无抖动、200–600ms。
设计一个 HUD 式「准星脉冲」：点击处生成一个 0×0 的 fixed 锚点，内含
1) 3px 直角方核（scale 1→1.8 淡出 320ms）
2) 28px 细环（scale .35→2 淡出 560ms）
3) 四条沿轴刻度（11→28px 外滑 460ms）
颜色跟随站点双主题；仅 pointerdown 触发；reduced-motion 不生成；并发上限 10；动画结束用定时器清理
（不要监听每个子元素的 animationend）。请同时更新验收断言：点击会出现、会清理、reduced-motion 抑制，
并确认点击烟花脚本已从产物中移除。
```
